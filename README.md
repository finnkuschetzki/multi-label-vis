# About

This repository contains the code for my Bachelor's thesis "Instance-Centric Visualization of Probabilistic Multi-Label Data for Image Classification".

# Setup

To use this project, download the [COCO dataset](https://cocodataset.org/#download) and

- place annotation files in `coco_dataset/data/annotations`
- place image files in `coco_dataset/data/images`
